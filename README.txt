Saudi Tourism Project
=====================

How to run:
1. Open the folder.
2. Double-click index.html
3. The website will run directly in the browser.

Project files:
- index.html
- style.css
- script.js

Features:
- Search by Saudi city name
- Display famous and new tourist places
- Show image, short description, and booking/visit link
- Filter by place type
- Responsive design

Supported cities:
- Riyadh / الرياض
- Jeddah / جدة
- AlUla / العلا
- Abha / أبها
- Taif / الطائف
- Khobar / الخبر

You can easily add more cities inside script.js
